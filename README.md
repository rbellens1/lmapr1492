# LMAPR1492 - Physique des matériaux

Bienvenue dans le dépôt GitHub du cours **LMAPR1492 - Physique des matériaux**. Ce dépôt contient des ressources et du matériel pédagogique pour le cours dispensé à l'Université Catholique de Louvain (UCLouvain).

## Description

Ce cours explore les principes fondamentaux de la physique des matériaux, avec un accent particulier sur leurs propriétés mécaniques, thermiques et électriques. Les ressources incluent des notes de cours, des supports visuels et des exercices pour accompagner les étudiants dans leur apprentissage.

### Fiche de cours

La fiche de cours officielle est incluse dans ce dépôt au format PDF :
- [cours-2025-lmapr1492.pdf](cours-2025-lmapr1492.pdf)

Elle contient des informations détaillées sur les objectifs d'apprentissage, les prérequis et la structure du cours.

## Contenu du dépôt

- **Jupyter Notebooks** : Des notebooks interactifs pour illustrer les concepts abordés en cours.
- **Scripts Python** : Des scripts pour effectuer des simulations ou des analyses simples en lien avec le cours.
- **Fiche de cours** : Une description complète du contenu et des objectifs du cours.
